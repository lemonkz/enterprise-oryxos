# Roadmap

Philosophy: **slow is smooth, restrained and focused**. Make the single-node runtime kernel rock-solid first; grow distributed capabilities on top.

## Phase 1 (current): single-node runtime kernel

The five core capabilities, running and managing a fleet of agents on one node:

- Provider routing + ReAct engine + Memory + Tools + Web Service
- One directory = one agent (AGENT.md)
- Cron scheduling, IM channels, full-chain audit

## Phase 2 (planned): distributed harness

Stateless instances, externalized state, multi-replica deployment for scale and high availability.

## Phase 3 (vision): cross-node agent collaboration

An agent communication substrate: discovery, delegation, and reliable async coordination across nodes.

## Horizontal capabilities

Multi-tenancy, SSO, full audit, Tool Policy, observability, and the web console land progressively alongside each phase.

## Long-term goal

Graduate into the Apache Software Foundation as a top-level project.
